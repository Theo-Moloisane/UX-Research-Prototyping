# UX-Research-Prototyping

## Overview
Conducted user experience research to identify usability issues in an existing website and designed improved interface prototypes using Figma.

## Features
- User research
- Usability analysis
- Survey and interview planning
- Low-fidelity wireframes
- Medium-fidelity wireframes
- High-fidelity prototypes

## Technologies
- Figma

## Skills Demonstrated
- UX Research
- User Analysis
- Wireframing
- Prototyping
- Interaction Design

## Project Outcome
Applied UX research methodologies to create user-centered design solutions that improve usability and accessibility.
